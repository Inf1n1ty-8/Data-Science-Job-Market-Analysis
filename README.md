## Project Overview

This project analyzes 1,000+ job postings to identify salary trends, location hotspots, and technical skill demand in data-related roles across the US and India.

The project was built using Power BI, Power Query, and DAX. The goal is to convert raw job-posting data into an interactive dashboard for job-market and career-related insights.

## Key Questions

1. Which technical skills are most commonly requested in data-related roles?
2. How do salaries vary by role, location, and work type?
3. Which locations show stronger demand for data-related jobs?
4. How do remote, hybrid, and on-site roles compare?
5. Which skill combinations appear frequently in job descriptions?

## Tools Used

## Key Insights

- Python and SQL appear frequently in data-related job postings.
- Salary patterns vary by location, role type, and work arrangement.
- Major tech hubs show stronger demand for data-related roles.
- SQL and Power BI commonly appear together in analytics-related job descriptions.

## Technical Workflow

1. Imported raw job-posting data into Power BI.
2. Cleaned and transformed fields using Power Query.
3. Parsed skill-related columns into analyzable categories.
4. Built a data model connecting job, company, location, and skill information.
5. Created DAX measures for job counts, salary summaries, and skill demand.
6. Designed an interactive Power BI dashboard with maps, charts, and slicers.

## Limitations

- The analysis depends on the quality and completeness of the job-posting dataset.
- Missing or unclear salary values may affect salary-based conclusions.
- The dataset is a sample of job postings and may not represent the entire job market.
- The dashboard is not a live real-time job tracker.
