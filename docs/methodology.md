# Methodology

## Project Goal

The goal of this project is to analyze data-related job postings and identify patterns in salary, technical skill demand, job roles, locations, and work arrangements.

The final output is an interactive Power BI dashboard that helps summarize job-market trends in a clear and visual way.

## Dataset

The dataset contains job-posting information for data-related roles.

The main fields used in the analysis include:

- Job title
- Country or location
- Salary information
- Technical skills
- Work arrangement
- Company-related information

## Data Cleaning

The data was cleaned and transformed using Power Query in Power BI.

The main cleaning steps included:

1. Imported the raw job-posting dataset.
2. Removed or handled missing and unclear values.
3. Standardized column names for easier analysis.
4. Checked salary-related fields for consistency.
5. Parsed skill-related information into usable categories.
6. Prepared the data for dashboard visualization.

## Data Model

The dashboard was built using a structured Power BI data model.

The model was designed to support analysis of:

- Job counts
- Skill frequency
- Salary trends
- Country/location-based demand
- Role-based comparisons

## Dashboard Design

The dashboard includes visuals for:

- Total job count
- Total skill count
- Median yearly salary
- Skills per job
- Top skills in data roles
- Top-paying data jobs
- Country and job-title filtering

Interactive slicers were added to allow users to filter the dashboard by job title and country.

## Limitations

- The analysis depends on the quality and completeness of the dataset.
- Some job postings may have missing or unclear salary values.
- The dataset is a sample of the job market and may not represent every available data-related job.
- The dashboard is not a live real-time job tracker.
